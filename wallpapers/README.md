# Wallpapers

Hình nền dùng cho máy tính và VS Code.

## Quy ước

- Tên file chữ thường, nối bằng dấu gạch, không dấu cách: `dark-purple-gradient.png`.
- Mỗi file dưới 5 MB (nén ảnh nếu cần).
- Chỉ để ảnh bạn có quyền chia sẻ công khai (ảnh tự làm, ảnh giấy phép tự do). Ảnh có bản quyền của người khác thì chỉ lưu link nguồn.
